# RecipeSuggest

RecipeSuggest is an Angular application backed by a simple Flask API. It lets you pick ingredients and generates a complete recipe using Google Gemini. The AI composes a title, ingredients, instructions and cooking tips for you.

## Features
- Choose from a range of fruit, vegetables, spices and other categories
- Select the cuisine and course type you want
- Animated background with playful food particles
- Recipes are generated by Google Gemini through the Flask backend

## Running Locally
1. Install backend dependencies:
   ```bash
   cd backend
   pip install -r requirements.txt
   ```
2. Start the Flask server:
   ```bash
   python app.py
   ```
3. In another terminal install the Angular packages and start the dev server:
   ```bash
   npm install
   npm start
   ```
4. Open `http://localhost:4200` in your browser and craft a recipe.

## Development
This project uses the Angular CLI. Common commands include:

- `ng generate component my-comp` – scaffold a new component
- `ng build` – build the application
- `ng test` – run unit tests (requires Angular CLI installed globally)
